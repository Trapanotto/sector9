# Credits

Only CC0 (public domain) third-party assets may be added. Append-only: one section per workstream, one entry per
asset with source URL, author, licence and local path.

## Code dependencies
- three.js 0.170.0 — MIT licence — https://threejs.org (npm `three`)
- Vite 5 — MIT licence (build tool only)

## Core (v2 foundation)
- No third-party art or audio assets are used by the v2 foundation: the greybox, lighting bake, sky, OSD and
  post-processing are generated by code in this repository.
- v1's CC0 Poly Haven textures/models (`public/assets/**`, polyhaven.com, CC0) were removed from the tree and remain
  available in git history (commit `083b978`): `git checkout 083b978 -- public/assets/textures/<name>`. Whoever
  restores one records it again below.

## A — world art
- No third-party assets. All prop/machine geometry (`src/world/art/*.js`) and the art texture atlas (painted at load
  time on a canvas by `src/world/art/atlas.js`: cardboard, stretch film, pallet wood, rack perforation, signs,
  labels, …) are generated by code in this repository. Fonts used for sign lettering are the browser's system
  sans-serif fonts (rendered at runtime, not shipped). Brand names on props ("HOLM", "NORDWARE") are fictional.

## B — materials / lighting
World material layers in `public/assets/materials/` (512², down-sampled and repacked by
`scripts/b-build-materials.mjs` from v1's copies in git history 083b978). All Poly Haven, author credits as listed
on polyhaven.com, licence CC0 1.0:
- `floor_*` — "Concrete Floor Worn 001", https://polyhaven.com/a/concrete_floor_worn_001
- `concrete_*` — "Concrete Wall 008", https://polyhaven.com/a/concrete_wall_008
- `asphalt_*` — "Worn Asphalt", https://polyhaven.com/a/worn_asphalt
- `plate_*` — "Metal Plate", https://polyhaven.com/a/metal_plate
- `wood_*` — "Weathered Brown Planks", https://polyhaven.com/a/weathered_brown_planks
- `lino_*` — "Old Linoleum Flooring 01", https://polyhaven.com/a/old_linoleum_flooring_01
- `trapez_*`, `sandwich_*`, `block_*`, `cardboard_*`, `wrap_*`, `grating_*`, `paint_*`, `flat_*` — generated
  procedurally by `scripts/b-build-materials.mjs` (no third-party data).
- Lightmaps, probes, environment cubes (`public/bake/*`) and the sky are generated by code in this repository.

## C — player / weapon / fx
- First-person arms + pistol (public/assets/arms/fp_arms_pistol.glb): built by scripts/chars/ from CC0 MakeHuman
  meshes, the CC0 Toigo sweater/glove meshes and procedural pistol geometry — every source with URL, author and
  licence in **CREDITS-CHARS.md**.
- Weapon FX (muzzle flash, casings, impacts, decals, tracers, dust): generated by code (src/fx/fx.js), no files.

## D — enemies
- Characters, animations, enemy weapons, hit boxes (public/assets/chars/**): all sources CC0 (Quaternius Universal
  Animation Library 1+2, MakeHuman base mesh + CC0 asset packs) — full table in **CREDITS-CHARS.md**.

## E — audio
- Every file in public/assets/audio/** (recordings, impulse responses in ir/) is derived from CC0 / public-domain
  recordings (Freesound CC0 uploads, Kenney CC0 packs) — one row per source with URL, author, licence and output files
  in **CREDITS-AUDIO.md** (generated by scripts/audio/build-audio.py, which refuses non-CC0 sources).

## F — director / UI
- No third-party assets. The UI uses the system's own fonts (no web fonts shipped); all texts are original.

## Summary of shipped third-party files
public/assets/materials/ (Poly Haven, CC0, section B), public/assets/chars/ + public/assets/arms/ (CC0,
CREDITS-CHARS.md), public/assets/audio/ (CC0, CREDITS-AUDIO.md). Everything else under public/ is generated by
code in this repository.
