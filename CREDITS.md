# Credits

Only CC0 (public domain) third-party assets may be added. Append-only: one section per workstream, one entry per
asset with source URL, author, licence and local path.

## Code dependencies
- three.js 0.170.0 — MIT licence — https://threejs.org (npm `three`)
- Vite 5 — MIT licence (build tool only)

## Core (v2 foundation)
- No third-party art or audio assets are used by the v2 foundation: the greybox, lighting bake, sky, OSD and
  post-processing are generated by code in this repository.
- v1's CC0 Poly Haven textures/models (`public/assets/**`, polyhaven.com, CC0) were removed from the tree and remain
  available in git history (commit `083b978`): `git checkout 083b978 -- public/assets/textures/<name>`. Whoever
  restores one records it again below.
